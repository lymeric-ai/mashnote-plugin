이 Claude 대화를 MashNote 활동 피드에 기록하라. 대화가 길고 주제가 여러 개면
주제별로 나눠 여러 건으로 남길 수 있다. 이미 기록한 단위는 건너뛰고 새 결과만 추가한다.
이 도구는 append-only이며 기존 기록을 덮어쓰지 않는다.

## 1. 기록 목적지
목적지는 **연결된 MashNote 서버가 정한다.** 서버 주소 하나가 워크스페이스 하나에
묶여 있으므로 `log_activity`·`list_recent_activity`에 `workspaceId`를 **넘기지 말고**,
어디에 기록할지 사용자에게 묻지 말 것. 기록은 그 워크스페이스에 들어가고 멤버에게
보인다.

- MashNote 서버가 **하나**면 그대로 쓴다.
- 서버가 **여러 개**(워크스페이스마다 하나)인데 사용자가 어느 워크스페이스인지 말하지
  않았으면 **한 번만** 물어본 뒤 그 서버의 도구를 쓴다. 같은 작업 단위를 두 서버에
  모두 기록하지 말 것.
- `list_workspaces`는 노트 읽기용이다. 기록 목적지를 고르려고 호출하지 말 것.

## 2. 시각(occurredAt)
현재 대화에서 실제 작업 시각을 알고 있으면 UTC 오프셋이 포함된 ISO 8601로 보낸다.
모르면 `occurredAt`을 생략한다(서버가 기록 시각으로 채움). 시각을 지어내거나
최근 수정된 다른 세션의 transcript를 현재 대화로 추측하지 말 것.

## 3. 이미 기록한 것 확인
`list_recent_activity`를 호출해(인자 없이) 이 워크스페이스에 이미 남긴 활동을 본다.
각 항목의 `idempotencyKey`·`occurredAt`·`title`로 어떤 단위가 이미 있는지 판단한다.
**직전 기록 이후 새로 한 작업만** 남기면 된다 — 이미 있는 단위를 통째로 다시 만들지 말 것.

## 4. 단위로 나누고 키 정하기
분할 단위는 **의미 있는 작업 덩어리(하위 주제·마일스톤)**다. 단위마다 `log_activity`를
한 번씩 호출하고, 각 건의 `occurredAt`은 실제 시각을 알 때만 포함한다(2번).

- **뚜렷이 다른 주제 여러 개**를 다뤘으면 주제마다 나눈다.
- 주제가 하나여도 **분량이 크고 독립적으로 제목 붙일 만한 산출물이 여럿**이면 그 단위로
  나눈다. 분량/길이는 "쪼갤지 검토하라"는 신호일 뿐, 경계는 **의미 단위**로 잡는다.
- 같은 작업을 잠깐 떠났다 다시 이어가는 정도면 **아직 기록하지 않았다면 한 건으로 합친다**.
  이미 기록한 뒤의 새 결과는 별도 건으로 남긴다.
- 글자 수만으로 기계적으로 쪼개지 말 것 — 각 조각은 그 자체로 의미 있는 결과를 가져야 한다.
- 단일 단위면 그냥 한 건으로 남긴다.

**키 규약** — 완료한 작업 단위마다 안정적인 `idempotencyKey`를 한 번 정한다.
예: `<현재 세션 식별자>-<작업 단위 식별자>`. 같은 호출을 재시도할 때는 같은 키를 쓴다.
- 이미 기록한 단위는 다시 호출하지 않는다. 동일 키 재시도는 기존 기록을 반환할 뿐
  내용을 갱신하지 않는다.
- 새 작업 결과는 새 키로 남긴다. 실제 시각을 모르면 키를 만들기 위해 시각을 지어내지 않는다.

## 5. 요약 규칙 (건마다)
- **title**: 60자 이내 한국어, 명사형 종결('~ 추가', '~ 변경', '~ 개선').
  '~했다' 같은 서술형 어미와 함수명·파일경로 등 코드 식별자 금지.
- **summary**: 1~2개 구절, 개조식 명사형 종결. 마크다운·백틱 금지.
- **points**: 변경이 여러 갈래일 때만 2~5개의 개조식 명사형 구절. 단일이면 생략.
- **detail**: 보고서용 상세 기록(마크다운 허용, 코드 식별자 사용 가능).
- 원문 대화 transcript는 보내지 말고 요약만 보낸다.

## 6. 결과 확인
도구가 성공했다고 확인한 뒤에만 기록 완료를 알린다. 응답의 `workspaceId`·`source`·
`visibility`를 기준으로 어디에 어떻게 저장됐는지 설명한다(워크스페이스 서버로 기록한
항목은 `workspace`, 즉 멤버 공개가 기본이며 사용자가 앱에서 항목별로 좁힐 수 있다).
